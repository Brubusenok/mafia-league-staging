# База данных (Supabase)

## Файлы

- `migrations/20261030000000_init.sql` — схема: таблицы, правила доступа, проверки игровой логики.
  Запускается один раз в пустой базе.
- `seed.sql` — **демонстрационные** данные (12 игроков, ближайший вечер, одна прошедшая игра).
  Нужны только для пробы, настоящие данные клуба потом вносятся через админку.

## Как поднять базу

1. Зарегистрируйтесь на https://supabase.com и создайте проект (бесплатный тариф, регион — Frankfurt).
   Запишите пароль от базы — он нужен только вам, нам он не нужен.
2. В проекте откройте **SQL Editor → New query**, вставьте целиком содержимое
   `migrations/20261030000000_init.sql` и нажмите **Run**.
3. Для пробы повторите то же с `seed.sql`.
4. Откройте **Project Settings → API** и скопируйте:
   - **Project URL**;
   - **Publishable key** (начинается с `sb_publishable_`).
   Эти два значения можно присылать в чат — они публичные.
   **Secret key / service_role никому не присылайте и никуда не вставляйте.**
5. На своём компьютере скопируйте `.env.example` в `.env.local` и вставьте оба значения.

## Как сделать себя администратором

1. **Выключите самостоятельную регистрацию.** В Supabase откройте **Authentication → Sign In / Providers**
   и выключите **Allow new users to sign up**. Пока в клубе входят только администраторы,
   создавать аккаунты должны только вы.
2. **Создайте пользователя.** **Authentication → Users → Add user → Create new user**: введите свою
   почту и придуманный пароль, включите **Auto Confirm User**.
3. **Назначьте себя администратором.** В **SQL Editor** выполните (подставьте свою почту):

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'ваша@почта';
```

4. Откройте сайт, нажмите **Войти** и введите эту почту и пароль. Пароль никому не присылайте.

## Главные правила

- Читать клубные данные (игроки, вечера, партии) может любой посетитель.
- Роли игроков в партии скрыты, пока партия не завершена.
- Менять данные может только администратор. Игрок с аккаунтом управляет только своей записью на вечер.
- Партию нельзя завершить с неверным составом (10 или 9 игроков, нужный набор ролей, ведущий не за столом).
