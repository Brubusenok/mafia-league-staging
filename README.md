# Mafia League

Сайт клуба спортивной Мафии в Граце. Next.js App Router + TypeScript + Tailwind,
Supabase/Postgres/Auth, целевой хостинг Vercel. Сохранены регистрация, запись на
вечера, административные формы, профили, история и обучение.

## Локальная разработка

Node 24 рекомендуется (не ниже 22.13.0).

```sh
npm ci
npm run dev
```

Скопируйте `.env.example` в `.env.local` и укажите публичные параметры **тестового**
проекта Supabase. Подготовка схемы: [supabase/README.md](supabase/README.md).
Без параметров базы доступен демонстрационный режим витрины.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

`npm test` не использует сеть или действующую базу: in-memory PostgreSQL/PGlite,
синтетические пользователи, эталоны League Skill и движок ведущего v33.
CI запускает те же проверки.

## League Core

Восстановлена оригинальная `team-logit-v1` с неопределённостью. Short9 остаётся
в истории и статистике, исключаясь из основного Skill. Рейтинг, профили и
графики используют единый расчёт из согласованного публичного снимка.

Новая миграция `20261030030000_league_core.sql` подготовлена для закрытых заметок,
целостности партий и транзакционных сохранений с проверкой версии. **В действующей
клубной базе она в рамках спринта не выполнялась; deployment не делался.**

Подробности, ограничения, порядок проверки миграции и основа переноса пульта:
[docs/CORE_SPRINT.md](docs/CORE_SPRINT.md).
